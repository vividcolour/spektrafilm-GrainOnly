A smaller format enlarges the frame more, so grain and halation grow. Format sets how many microns each pixel covers.

Couplers add the edge contrast and colour separation a developer gives. Grain is grown per dye sublayer from the stock's measured curves.

Filter values are Kodak CC units added to the enlarger's neutral filtration for this film and paper. More yellow makes the print bluer.

Previews run at screen size, where grain averages out the way it does in a small print. Use 1:1 to check grain at full resolution.
